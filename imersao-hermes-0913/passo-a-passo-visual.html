1. Comprar ou abrir a VPS

Humano faz

Abre o link da Hostinger, escolhe um plano VPS KVM e finaliza a compra.

Abrir Hostinger VPS

cliquecontrataçãologin hPanel

Máquina faz

Nada ainda. Aqui é só compra/acesso humano.

2. Entrar no hPanel e clicar em VPS → Gerenciar

Humano faz

  1. Entra na conta da Hostinger.
  2. Clica em VPS.
  3. Encontra a VPS criada.
  4. Clica em Gerenciar.

Máquina faz

Nada ainda. Ainda estamos pegando acesso.

3. Pegar IP, usuário SSH e porta

Humano copia

  • IP da VPS
  • Usuário SSH, normalmente root
  • Porta SSH, normalmente 22

Esses dados entram no instalador assistido.

Máquina gera

Com esses dados, a página monta o comando:

ssh root@IP_DA_VPS

4. Opção mais fácil: Web Console da Hostinger

Humano faz

Se o aluno não sabe usar terminal no computador, manda abrir Web Console ou Terminal dentro da Hostinger.

Máquina recebe

Com o console aberto, o aluno cola o comando de instalação:

curl -fsSL https://hlreboques-oss.github.io/projeto-sites-demos/imersao-hermes-0913/install.sh | bash

5. Colar o instalador Hermes na VPS

Humano faz

Copia o comando abaixo e cola no terminal/Web Console da VPS.

Máquina faz

  • Instala dependências
  • Instala Hermes
  • Cria pastas
  • Baixa o kit da imersão
curl -fsSL https://hlreboques-oss.github.io/projeto-sites-demos/imersao-hermes-0913/install.sh | bash

6. Conectar LLM: ChatGPT/Codex por OAuth, não API

Humano faz

Para usar assinatura ChatGPT/Codex no Hermes, o caminho certo é pelo provider OpenAI Codex, com login OAuth/device code.

não é OpenAI API keyé hermes modelChatGPT or Codex Subscription

Quando o Hermes mostrar um link/código, o aluno abre no navegador, faz login e autoriza.

Máquina faz

Rode na VPS:

hermes model

Escolher:

ChatGPT or Codex Subscription / OpenAI Codex

Alternativa avançada, se precisar forçar login pelo navegador:

hermes auth add openai-codex --browser

Correção importante para a aula: OpenAI API Key é outra opção, separada e paga por token. Para assinatura ChatGPT/Codex, o passo certo é OAuth/device code pelo hermes model.

7. Opção grátis/barata: OpenRouter + Nemotron

Humano faz

  2. Cria chave.
  3. Escolhe modelo gratuito, se disponível.

OpenRouter Keys Nemotron grátis

Máquina faz

hermes model

Escolher OpenRouter e usar modelo:

nvidia/nemotron-3-ultra-550b-a55b:free

8. Criar bot no Telegram

Humano faz

  1. Abre o BotFather.
  2. Envia /newbot.
  3. Escolhe nome.
  4. Escolhe username terminando em bot.
  5. Copia o token.

Abrir BotFather

Máquina faz

Nada ainda. O token será usado no hermes gateway setup.

9. Pegar Telegram user ID

Humano faz

  1. Abre o userinfobot.
  2. Envia /start.
  3. Copia o ID numérico.

Abrir userinfobot

Máquina usa

Esse ID vira o usuário autorizado no Telegram.

10. Configurar Telegram no Hermes

Humano informa

  • Token do BotFather
  • Telegram user ID

Máquina configura

hermes gateway setup

Depois testa:

hermes gateway

Se respondeu, deixa permanente:

hermes gateway install
hermes gateway start
hermes gateway status
