Instalar, conectar e operar um agente Hermes próprio.

Guia digital para coordenar a aula: VPS, Hermes, Telegram, arquivo base, prospecção, social selling e rotina operacional com segurança.

Começar instalação Conectar Telegram Prompts prontos

1. Comando inicial na VPS

Depois que o aluno contratar a VPS Ubuntu e entrar por SSH, ele cola:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Depois configura o Hermes:

hermes setup --portal

Alternativa manual: hermes setup ou hermes model.

2. Entrar na VPS

ssh root@IP_DA_VPS

Se pedir confirmação, digitar yes. Depois a senha da VPS.

3. Testar no terminal

hermes

Mensagem de teste:

Responda apenas: Hermes funcionando.

4. Telegram

Criar bot
Abrir @BotFather, enviar /newbot, escolher nome e username terminando em bot.
Copiar token
Token é segredo. Não mandar em grupo.
Pegar user ID
Abrir @userinfobot, enviar /start e copiar o ID numérico.
Configurar gateway
hermes gateway setup
Escolher Telegram, colar token e user ID permitido.
Testar
hermes gateway
Mandar “oi” para o bot no Telegram.
Deixar permanente
hermes gateway install
hermes gateway start
hermes gateway status

Prompt para primeiro chat do agente

Você é meu agente operacional particular rodando na minha VPS.

Leia todos os arquivos da pasta ~/imersao-hermes, começando por:
~/imersao-hermes/01_BASE_DO_AGENTE_HERMES.md

Use isso como base operacional deste projeto.

Regras:
- não envie mensagem, publique, curta, siga ou comente sem minha autorização;
- nunca peça senha ou código 2FA no chat;
- quando precisar de login, abra o navegador e eu faço manualmente;
- não faça spam;
- se algo falhar, diga o erro real;
- trabalhe uma etapa por vez quando envolver conta externa.

Primeiro, me faça 7 perguntas para entender minha oferta, público, cidade/região, ticket, principais produtos, redes sociais e meta comercial para os próximos 7 dias.

Prompt de prospecção

Minha oferta é [oferta]. Meu público é [público]. Minha região é [cidade]. Quero que você monte minha primeira base com 20 leads públicos, qualifique cada um e escreva mensagens personalizadas. Não envie nada ainda.

Prompt de social selling

Abra o Instagram no navegador. Eu vou fazer login manualmente. Depois analise o perfil @perfil_relacionado e me traga 10 perfis com fit para minha oferta. Não curta, siga ou comente sem eu aprovar.
