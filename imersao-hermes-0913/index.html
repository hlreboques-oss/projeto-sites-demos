Mapa prático: humano faz x máquina faz

Humano faz

clicarcriar contacopiar dadoslogin manual

  1. Contrata/abre VPS na Hostinger.
  2. Copia IP, usuário SSH e porta.
  3. Cria bot no BotFather.
  4. Pega Telegram user ID.
  5. Autoriza LLM por OAuth ou cria chave OpenRouter.

Máquina faz

instalabaixa kitroda gateway

  1. Instala dependências.
  2. Instala Hermes.
  3. Baixa o kit da imersão.
  4. Configura gateway Telegram.
  5. Deixa o agente pronto para conversar.

Instalador assistido

1. Entrar na VPS

ssh root@IP_DA_VPS

2. Instalar Hermes

curl -fsSL https://hlreboques-oss.github.io/projeto-sites-demos/imersao-hermes-0913/install.sh | bash

LLM: ChatGPT/Codex por OAuth e opção grátis

ChatGPT/Codex, com assinatura

não é OpenAI API Keyé OAuth/device code

Na VPS:

hermes model

Escolher:

ChatGPT or Codex Subscription / OpenAI Codex

Se precisar abrir pelo navegador:

hermes auth add openai-codex --browser

OpenRouter + Nemotron, grátis/barato

Serve para aluno sem crédito OpenAI. Pode ter limite/fila.

  1. Abrir openrouter.ai/keys.
  2. Criar chave.
  3. Usar modelo nvidia/nemotron-3-ultra-550b-a55b:free.
hermes model
# escolher OpenRouter
# modelo: nvidia/nemotron-3-ultra-550b-a55b:free
